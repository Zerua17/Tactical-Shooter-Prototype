# EN

## Tactical Shooter Prototype


3D Isometric Tactical Game Prototype, made with Unity and C#

This is a personal project I started to explore and implement technical systems, mechanics and gameplay for a 3D Isometrical Tactical game.
Heavily inspired by XCOM and other turn-based tactic games.

Technologies
-
Engine: Unity

Language: C#

Version Control: Git/GitHub

Platform: PC


Current Features
-
So far, the project includes:

-Tracking the mouse position on the game world.

-Moving a single character to clicked place on the ground.


Assets & Resources
-
This project uses free assets from the Unity Store to help with visualization.

Currently used assets include:

-Soldier Character model

-Environment Construction models (Walls, floors and other props)

-Materials





# ES

## Protipo de Juego de Disparos Táctico

Prototipo de un Juego Isométrico Táctico en 3D, hecho en Unity con C#

Este es un proyecto personal que empecé para explorar e implementar sistemas técnicos, mecánicas y jugabilidad para un juego 3D Táctico Isométrico.
Fuertemente inspirado por XCOM y otros juegos tácticos por turnos.

Tecnologías
-
Motor: Unity

Lenguaje: C#

Control de Versiones: Git/GitHub

Plataforma: PC


Funciones Actuales
-
Hasta ahora, el proyecto incluye:

-Rastrear la posición del ratón en el mundo del juego.

-Mover un único personaje a una posición clickeada en el suelo.


Assets y Recursos
-
Este proyecto hace uso de paquetes de assets gratuitos descargados de la Tienda de Unity para ayudar con la visualización.

Assets usados actualmente incluyen:

-Modelo de Soldado para el personaje

-Modelos de Construccion de Entorno (Paredes, suelos, etc)

-Materiales
